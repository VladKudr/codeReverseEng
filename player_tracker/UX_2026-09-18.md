# UX player_tracker — сценарии, действия, упрощения (2026-09-18)

Макеты: https://claude.ai/artifact/Tt9Pea9Yr8eqq5aJDiQ6WW (холст «Player Tracker — новый UX», 6 экранов для компьютера
и 3 для телефона). В коде ничего не менялось — это проект интерфейса на согласование.

## 1. Для кого

**Родитель** снял матч на телефон и хочет увидеть: где играл ребёнок, сколько бегал, что подтянуть. Не знает слов
«трек», «гомография», «YOLO». Чаще всего смотрит с телефона. Готов потратить 1–3 минуты на уточнения, если понятно, что
это даст. **Специалист** (автор проекта) — второй пользователь: ему нужны параметры, метрики слежения, файлы; для него
отдельный раздел, а не общий экран.

## 2. Что не так сейчас (инвентаризация)

Одна страница, ~70 элементов управления, 17 блоков подряд: ролик, задачи, выбор игрока, 14 технических параметров
(веса YOLO, imgsz, устройство, OCR…), результат, видео, доска, исправление цели, поправки, события, итог, поле на видео,
схема поля, метрики, ИИ-разбор, метрики слежения, ошибки, оценка по разметке, файлы.

| Проблема | Пример |
|---|---|
| Технические параметры — на первом экране | «Веса YOLO», «imgsz» видит родитель до запуска |
| Нумерация шагов сбита | «1. Ролик», «3. Задачи», «2. Выбор игрока» |
| Уточнения разбросаны и не объясняют пользу | состав — под доской, поле — ниже итога, свои ворота — в двух местах |
| Один щелчок по видео значит разное | выбрать человека / выключить / поставить точку — зависит от невидимого состояния |
| Инструменты вместо вопросов | «отметьте лишних на кадре, где их побольше» — работа, которую система может свести к «да / нет» |
| Разметка поля — 4 ручки + 2 режима + поворот соответствия | родителю нужно понимать геометрию |
| Нет «дома» | список задач с id `578f810577c1` вместо «Турнир, 14 сентября» |
| Фоновые этапы (мяч, привязка кадров) — в строке статуса | непонятно, можно ли уже смотреть |
| Телефон | страница шириной 979 px, не адаптирована |

## 3. Сценарии использования

| № | Сценарий | Сейчас (действий) | Предлагается |
|---|---|---|---|
| С1 | Первый разбор: загрузить → показать ребёнка → получить результат | ~12: выбрать файл, загрузить, выбрать ролик, момент, точка, возраст, позиция, формат, (14 параметров на виду), запустить, открыть задачу | 5: «Новый разбор» → файл → касание по ребёнку → возраст + формат → «Начать» |
| С2 | Вернуться к готовому разбору | найти id в списке задач | «Мои матчи»: карточки с датой, кадром, статусом |
| С3 | Дождаться обработки | читать строку «мяч ищется 1200/2488» | карточка: «Игроки найдены — можно смотреть. Мяч: 62 %, ~4 мин» |
| С4 | Смотреть игру: видео + доска, прыгать по моментам | видео и доска на разных высотах страницы, события — списком ниже | один экран: видео слева, доска справа, под видео лента «Моменты» |
| С5 | Игрока потеряли — показать, где он | щёлкнуть красное на шкале → «Исправить цель» → ±кадры → точка → «перестроить» | пункт «Один раз потеряли игрока — Показать» ведёт сразу на нужный кадр: одно касание по ребёнку |
| С6 | Убрать лишних людей (тренеры, зрители) | пауза → щелчок → щелчок по каждому, на нескольких кадрах | 5–6 вопросов «Этот человек играет? Да / Нет» только про тех, в ком система не уверена |
| С7 | Замена: игрок ушёл / вышел | выбрать человека → «с этого момента» | в меню человека: «Ушёл с поля на 0:26 (замена)» |
| С8 | Доска кривая — уточнить поле | открыть редактор, выбрать режим, таскать 4 точки, поворот, ворота, размеры | 4 касания по очереди с лупой + касание своих ворот; режим и поворот система выбирает сама |
| С9 | Прочитать показатели | таблица метрик с терминами | 3 крупные цифры + «Где играл» + пояснения человеческим языком и нормы по возрасту |
| С10 | Получить советы, задать вопрос | блок ИИ-разбора с формой профиля | 3 карточки (получается / подтянуть / упражнение) со ссылкой на момент + поле вопроса |
| С11 | Поделиться с ребёнком, тренером | нет | «Поделиться карточкой» (картинка с цифрами) |
| С12 | Специалист: параметры, метрики слежения, файлы | всё на общей странице | раздел «Для специалиста» (ссылка в шапке и сворачиваемый блок в «Новом разборе») |

## 4. Принципы упрощения

1. **Сначала результат, потом уточнения.** Разбор показывается сразу после этапа 1; всё ручное — необязательные улучшения.
2. **Один список «Сделать разбор точнее»** вместо разбросанных инструментов. У каждого пункта: что не так, сколько займёт
   («10 секунд», «около минуты», «4 касания»), кнопка. Шкала точности из трёх ступеней (базовая / хорошая / отличная)
   объясняет, зачем это делать. Источники пунктов уже есть в данных: отрезки потери цели, `why`/`suggest` состава,
   `calibration.method` и `outside`.
3. **Вопросы вместо инструментов.** Состав: система сама решает про тех, в ком уверена (склейка + сходство), и
   спрашивает только про сомнительных, показывая лучший кадр человека. Ответ относится к человеку на весь матч.
   Порядок вопросов — по пользе: сначала люди, чей ответ разрешит больше всего похожих.
4. **Одно касание — одно значение.** Режим касания выбран явно переключателем под видео: Смотреть / Кто играет / Границы поля /
   Поправить игрока. В режиме меняется шапка (тёмная), чтобы было видно, что идёт уточнение, и есть «Готово».
5. **По одному шагу.** Поле: «Коснитесь дальнего правого угла» → лупа → следующий шаг. Схема справа показывает, какая
   точка сейчас. «Не вижу угла» — законный ответ (ставим по игрокам). Режим `sides`/`corners` и `rotation` выбираются
   автоматически по расположению точек; свои ворота — касанием.
6. **Человеческий язык.** «Трек» → «человек», «вне игры» → «не играет», «фокус» → «ваш игрок», «калибровка» → «границы поля»,
   «reg_stage» → «уточняем положение камеры».
7. **Честность о точности.** Там, где данные приблизительные (мяч найден на 56 % кадров), цифра подписана как приблизительная.
8. **Приватность на виду.** У поля вопроса: «ИИ получает только цифры разбора — видео и кадры никуда не отправляются».
9. **Телефон — основной.** Кнопки ≥ 44 px, нижняя шторка «Сделать разбор точнее», вопросы о составе — на весь экран
   с двумя большими кнопками.

## 5. Карта экранов (см. макеты)

1. **Мои матчи** — кнопка «Новый разбор», три шага словами, карточки матчей в трёх состояниях: готово / идёт обработка
   (уже можно смотреть) / черновик (нужно показать игрока).
2. **Новый разбор, шаг 2** — кадр с найденными людьми, касание по ребёнку («Это он»), перемотка ±5 с; справа: возраст,
   формат, позиция (необязательно); «Настройки для специалиста» свернуты; обещание по времени.
3. **Игра** — вкладки Игра / Показатели / Советы; видео + переключатель режима касания + шкала слежения + «Моменты»;
   доска; список «Сделать разбор точнее»; фоновые этапы — одной пилюлей в шапке.
4. **Кто играет** — вопрос с кадром и крупным изображением человека, причина сомнения; справа состав тремя группами
   (свои / соперник / не играют); сплошная рамка — решили вы, пунктир — решила система; меню человека с заменой.
5. **Границы поля** — шаг с инструкцией, лупа, «где бегали игроки», схема «что отмечаем», список шагов, «Не вижу угла».
6. **Показатели и советы** — крупные цифры с нормами по возрасту, «Где играл», блок про мяч с оговоркой о точности,
   советы со ссылками на моменты, вопрос ИИ.
7. **Телефон** — игра (видео, шкала, доска, шторка), вопрос о составе на весь экран, шаг разметки поля.

## 6. Что потребуется от серверной части (когда дойдёт до внедрения)

- Название матча и дата у задачи (сейчас только id); эскиз кадра для карточки.
- «Сомнительные люди» для вопросов: из `roster.resolve` — люди без пометок, у которых разница сходства с примерами мала,
  плюс `suggest`; лучший кадр человека (самая крупная необрезанная рамка без перекрытий).
- Порядок вопросов по числу фрагментов, которые ответ разрешит.
- Автовыбор `mode`/`rotation` разметки по четырём точкам (перебор 2 × 4 вариантов по `outside` и `rms_m`).
- Оценка «точность разбора» (ступени): доля потерь цели, доля сомнительных людей, способ калибровки, `outside`.
- Карточка «Поделиться»: PNG с цифрами и зоной игры.

## 7. Порядок внедрения (предложение)

1. Каркас: «Мои матчи» + «Новый разбор» (мастер) + экран «Игра» с вкладками; «Для специалиста» — отдельный раздел со старыми блоками.
2. Список «Сделать разбор точнее» поверх существующих инструментов (пока ведёт в текущие редакторы).
3. Вопросы о составе (сервер: сомнительные люди + лучший кадр).
4. Пошаговая разметка поля с автовыбором режима.
5. Показатели и советы человеческим языком; «Поделиться».
6. Телефонная вёрстка всех экранов.
